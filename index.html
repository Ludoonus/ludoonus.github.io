About

Most of my projects are connected to The Cycle: Frontier. I work with Unreal Engine 4 assets and interfaces, and use IDA when I need to understand how the game behaves.

The work ranges from menu changes and visual effects to compatibility fixes. I also build tools for inspecting and editing the content I’m working with.

I’m studying vulnerability research alongside these projects, including C, memory safety, and how compiled programs work.
